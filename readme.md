# Project installation
For installation I used Laravel's Herd application
- Install Laravel Herd
- Pick your stack versions:
  - PHP 8.4.17
  - Node 22.22.0

## Pull in the GIT repository
Find the public repository at https://github.com/RoelvanLierop/subservice, this will have all the files you need.
- Navigate to Herd's project directory and Pull the project's *dev branch*.
